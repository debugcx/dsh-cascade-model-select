# dsh-cascade-model-select

级联式（两级）模型选择器，替换 DeepSeek Harness Web GUI 内置的平铺分组模型选择器。

## 效果

- 输入框左下的模型按钮点击后，**一级菜单列出所有厂家**（DeepSeek 账号、DeepSeek 官方在前，其余按目录顺序；每行显示该厂家的模型数量，当前选中模型所属厂家带 ✓）。
- **悬停或点击厂家行，在旁边弹出二级菜单**，只显示该厂家的模型；厂家模型超过 6 个时二级菜单顶部带搜索框（支持不连续模糊匹配）。
- 「推理等级」仍在一级菜单顶部，点击后在一级菜单内切换到等级列表（与内置一致）。
- `/model` 命令保持原样（分组平铺弹窗，带搜索）。

## 工作原理

本插件注册到与内置选择器相同的作曲器席位 `conversation.input.model`，并通过同一组宿主契约取数与提交（`remote.session.modelCatalog()`、会话的 `modelSelection` 投影、`remote.session.selectModel()`）。安装时其 bundle 补丁会**自动停用内置的 `ui-model-selection`**；停用/卸载本插件后内置选择器自动恢复，两者不会同时占用席位。

模型名徽标扩展点 `conversation.input.model.label` 照常声明，第三方标签插件（如官方模型标签）在级联菜单中仍然生效。

## 安装

1. 侧栏 **Plugins** 页面 → 安装输入框粘贴本目录的绝对路径，例如 `F:\dsh\dsh-cascade-model-select`；
2. 安装即启用，页面上可以看到内置「Model selection」一行已被关闭；
3. 若界面未刷新，重开页面（或重启应用）一次。

## 卸载 / 还原

在 Plugins 页面关闭或移除本插件即可：bundle 补丁对内置 `ui-model-selection` 的停用随之撤销，原生选择器恢复原样。**不要**在启用本插件的同时手动重新打开内置的 Model selection，两者会竞争同一个席位。

## 修改后重新加载

`lib/client.js` 是手写的客户端 bundle（无需构建步骤）。编辑保存后，在 Plugins 页面把本插件关掉再打开（或重启应用）即可加载新版本。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| ↑ / ↓ | 在当前列表（厂家行 / 模型行 / 等级行）间移动 |
| → | 打开焦点厂家的二级菜单并进入 |
| ← | 关闭二级菜单回到厂家行 |
| Enter / Tab | 打开焦点行；在搜索框中选定高亮模型 |
| Esc / Shift+Tab | 先退出二级菜单/等级面板，再关闭整个菜单 |
